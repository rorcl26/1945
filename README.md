# 1945: 二戰空間（II War Space）
經典二戰街機風格直向捲軸空戰過關遊戲（Docker 容器化 / GPU 硬體加速與 CPU 軟體渲染雙支援）

---

## 遊戲特色與核心規則

1. **主戰機選擇**：
   - 於開場機庫中可自由挑選 4 款經典戰機，各自具備專屬機體造型、武器彈道與按鍵 `Z` 特技：
     - **P-38 閃電 (Lightning Strike)**：雙發機身高速攔截機，配備高射速穿甲火神砲。特技為「360 度翻轉閃避 (Barrel Roll)」。
     - **F4U 海盜 (Corsair Titan)**：重裝甲折翼機，配備大角度重型扇形散彈。特技為「全防禦能量護盾 (Full Shield)」。
     - **BF-109 獵鷹 (Falcon Interceptor)**：高機動優勢戰機，配備前向機砲與自動追蹤火箭。特技為「急速翻轉閃避」。
     - **零式改 幻影 (Zero Phantom)**：高科技能量戰機，配備高能穿透連鎖雷射。特技為「能量防護力場」。

2. **戰果獎勵與火力/護盾升級**：
   - 擊毀敵機或 BOSS 會掉落戰果寶物：
     - **[P] 武器戰力升級**：最高升至 LV.5，擴展主砲門數、追加側翼火砲與微型飛彈。
     - **[S] 護盾修復/增強**：修復生命力並重塑全防禦力場。
     - **[B] 戰術炸彈**：清除全畫面敵方彈幕並對敵軍造成巨幅爆破。
     - **[W] 武器變換/增幅**：強化現有彈幕威力。

3. **生命力與十分之一扣血防禦機制**：
   - 主戰機具備全防禦能力。
   - **每次遭受敵方子彈或撞擊時，精準損失十分之一 (10%) 生命力**（100 HP 中扣除 10 HP，滿血可承受 10 次中彈）。
   - **整場遊戲擁有五次完整的生命力 (5 條命)**。
   - 生命力耗盡前重生會獲贈 3 秒無敵保護光圈。

4. **實景山脈與海景視差滾動背景 (預載於 Docker 容器中)**：
   - 解決傳統色塊單調問題，內建高畫質航拍級實景圖資：破曉太平洋群島山脈、珊瑚礁海岸峽灣、火山熔岩海域、極地冰山凍海、午夜深海月色。
   - 具備多層視差滾動：實景底圖無縫循環、海洋動態波光漣漪、高空浮雲與投影、專屬大氣濾鏡光調。
   - 所有實景圖檔皆已預先建置打包封裝於 Docker 容器 `/app/assets/` 中。

5. **關卡中途敵主力聯合艦隊突入 (Armada Battle Group)**：
   - 每關航程中途（約 40% 進度）響起警報，敵方海上戰鬥群突入戰場：
     - **主力戰列艦**：3 連裝重型主砲齊射，航行伴隨巨大破浪航跡浪花。
     - **作戰航空母艦**：甲板跑道定期放飛零式艦載突擊戰機加入空戰。
     - **重巡洋艦 / 砲艇**：雙聯裝艦砲與密集防空彈幕阻擊。
   - 擊沉敵艦提供豐厚得分與保證掉落戰果寶物。

6. **中間敵機 1 至 2 擊潰敗機制**：
   - 中間各類常規敵機（零式偵察機、黃黑突擊機、雙發轟炸機）精準調整為 **打擊 1 至 2 次後潰敗**。
   - 第 1 擊命中：機身劇烈閃爍並開始拖曳受損發動機黑煙與火星。
   - 第 2 擊命中：徹底瓦解凌空爆炸！

7. **BOSS 2 到 5 分鐘持久史詩對決 (多階段複合裝甲)**：
   - 告別過往數秒熔化的脆皮問題，每關關底 BOSS 配置 **重裝複合鋼鐵裝甲** 與萬點以上生命槽，確保每場對決維持 **2 到 5 分鐘** 的持久策略拉鋸戰。
   - **三階段動態戰術轉換**：
     - **階段一（HP > 66%）**：重裝防衛巡弋，多管主砲齊射與扇形防禦彈幕。
     - **階段二（33% < HP <= 66%）**：近防對空防線，8 向螺旋彈幕與前向雷射陣列。
     - **階段三（HP <= 33%）**：核心暴走滅世（OVERDRIVE），赤熱過載全速機動與全螢幕毀滅彈幕。
   - HUD 頂部即時顯示 BOSS 對戰計時器（`⏱ 對戰時間: MM:SS / 05:00`）與分段階段標記。

8. **全新雷射戰果 [L] 與全自動追蹤敵軍系統**：
   - 擊破敵軍戰車、中型軍艦或空中敵機時有機會掉落 **[L] 雷射戰果**（璀璨青藍能量光圈）。
   - 我方戰機吃到 [L] 戰果後立即解鎖 **自動追蹤高能雷射 (Auto-Targeting Homing Laser)**：
     - 雷射光束具備高穿透力與弧形自動轉向追蹤功能。
     - 自動鎖定戰場上最近的敵軍（包括空戰敵機、地面裝甲戰車、海上戰艦與關底 BOSS）。
     - 組合體（2~3 機）伴隨僚機同步發射追蹤雷射，形成密不透風的全方位殲滅能量網！

9. **全方位復古合成音效與動態背景音樂 (BGM)**：
   - 內建 NumPy 程序化純淨音頻引擎，無需外部 mp3/wav 檔案，100% 穩定相容 Docker/無音效卡環境。
   - **動態戰鬥背景音樂 (BGM)**：熱血街機進行曲節奏，出擊時自動啟動循環播放。
   - **我軍射擊音效**：清脆穿透機砲聲與高能追蹤雷射專屬射擊脈衝音。
   - **所有敵軍被擊斃音效**：
     - 空中敵機：高頻爆裂加白噪音爆震。
     - 地面戰車：沉重金屬裝甲爆破與履帶碎裂聲。
     - 海上軍艦：深海水花湧起與重裝彈藥庫殉爆轟鳴。
     - 關底 BOSS：震天動地多階段滅世爆裂。

10. **中間陸地敵方戰車與海上敵方中型軍艦**：
    - **中間陸地陣地**：地表戰場中央構築島嶼防禦陣地，敵方裝甲戰車（Tank）於中間陸地部署巡弋並向我方發射高熱燃燒加農砲彈。
    - **海上中型軍艦 (Cruiser)**：中型巡洋艦頻繁巡航於左右開闊洋面海道，配備旋轉雙聯裝主砲、白色防浪砲布、金屬副砲與動態航跡湧浪。
    - **事先完成精緻多彩圖像**：所有戰車與軍艦圖形於遊戲開場預先完成繪製與高畫質快取（Pre-warm Sprites），多彩幾何迷彩、紅星徽章、海軍吃水赤線與柚木甲板細緻入微，運行 100% 零卡頓。

11. **最後敵方 (BOSS) 穩定外型戰術顯示與顯色擊破倒數資訊**：
    - 頂部 HUD 配置專屬 **敵艦戰術顯示框 (Tactical Target Frame)**：穩定清晰呈現關底敵艦真實造型與外型輪廓，不因煙霧或螢幕移動而模糊。
    - **需多久被擊斃資訊（顯色顯示）**：
      - 依據剩餘血量與我軍戰力換算預估擊破倒數：`⏱ 預估擊斃: XX分XX秒 (XXs)`。
      - **鮮明高對比顯色切換**：
        - 階段一（血量 > 66%）：璀璨明亮金黃色（`#FFF028`）。
        - 階段二（33% ~ 66%）：鮮豔螢光亮橘色（`#FFA514`）。
        - 階段三（血量 <= 33% 暴走）：耀眼狂暴霓虹赤紅（`#FF3246`）。

12. **畫面橫條紋全面去除**：
    - 移除波浪水平線條繪製，採用自然細膩的星芒微粒水花漣漪。
    - 修正畫面渲染管線雙緩衝衝突，徹底杜絕橫條紋與畫面撕裂現象。

13. **雙人協同作戰模式 (2-Player Cooperative Mode)**：
    - **模式選擇與超長實景解析度**：
      - **單人模式 (1P)**：背景畫面以 **960 * 10240** 實景長卷模式執行。
      - **雙人模式 (2P)**：背景畫面以 **1024 * 10240** 原生寬屏實景長卷模式執行。
    - **戰機 4 選 1 不重複機制**：
      - 進入雙人模式時，由第一人 (P1) 先從 4 款戰機中選擇一款。
      - 第二人 (P2) 只能從剩下的三種戰機中選擇，第一人已選之機種自動鎖定標記，不可重複。
    - **獨立雙人控制操作鍵位**：
      - **第一人 (P1)**：
        - 移動：`↑` `↓` `←` `→` 方向鍵
        - 射擊：`M 鍵`（連續齊射）
        - 特技：`Z 鍵`（翻轉閃避 / 防護罩）
      - **第二人 (P2)**：
        - 移動：`W` (上)、`X` (下)、`A` (左)、`D` (右)
        - 射擊：`V 鍵`（連續齊射）
        - 特技：`C 鍵`（特技功能）
    - **二人子彈外觀與尺寸**：
      - **色彩截然不同**：P1 子彈為金黃/青藍光芒，P2 子彈為翠綠/霓虹洋紅紫電，極致清晰好辨識。
      - **尺寸縮小二分之一**：子彈尺寸縮小為原本的 $\frac{1}{2}$（機砲 6x12，半徑 3），彈幕更細緻高精準。
    - **敵軍四向突入與數量加倍**：
      - 敵軍支援由 **上、下、左、右** 四個方向突襲空域，飛行軌跡與姿態全方位覆蓋。
      - 雙人模式下空中與地面敵軍數量、保底敵機數與波次頻率全數 **加倍** 湧現。
    - **終極雙大魔王 (Dual Bosses)**：
      - 雙人模式關底由 **兩隻大魔王 (Boss 1 與 Boss 2)** 同時登場展開雙重多階段彈幕夾擊，兩隻大魔王全部消滅方可結算過關。
    - **5 命滿血復活 (Y 鍵補滿)**：
      - 當其中任一玩家的 5 次完整生命力全部損失 (Lives = 0) 陣亡時，**按下 `Y` 鍵立即補滿 5 條命與 100 HP 滿血復活**，無縫重新投入戰鬥！

14. **操作方式一覽**：
    - **1P 單人模式**：
      - 移動：`↑` `↓` `←` `→` 方向鍵（或 `W` `A` `S` `D`）
      - 射擊：`M 鍵` 或 `空白鍵 (Space)`
      - 特技：`Z 鍵`
    - **2P 雙人模式**：
      - P1：方向鍵移動 · `M 鍵` 射擊 · `Z 鍵` 特技
      - P2：`W` `X` `A` `D` 移動 · `V 鍵` 射擊 · `C 鍵` 特技
      - 補命復活：`Y 鍵`（陣亡時補滿 5 命滿血復活）
    - **通用控制**：
      - `P 鍵`：暫停 / 繼續遊戲
      - `ESC 鍵`：退出遊戲
      - `Enter 鍵`：確認選單 / 重新開始

- **Windows 11 (x64) 免安裝直接執行版**：
  - 提供完整獨立執行目錄 [`Windows11_Release/1945-II-WarSpace-Win11-x64/`](file:///home/rorc3090/%E6%96%87%E4%BB%B6/GA/1945/Windows11_Release/1945-II-WarSpace-Win11-x64/) 與封裝壓縮檔 [`II-WarSpace-1945-Win11-x64.zip`](file:///home/rorc3090/%E6%96%87%E4%BB%B6/GA/1945/II-WarSpace-1945-Win11-x64.zip)。
  - 內建原生 64-bit Windows GUI 啟動器 **`1945-II-WarSpace.exe`**（具備 Windows 11 `PerMonitorV2` 高 DPI 感知清單、專屬戰機圖示與 UTF-8 支援）。
  - 內嵌完整 Windows 64-bit 執行環境（Python 3.12 Embeddable + Pygame 2.6 SDL2 + NumPy + 繁體中文字型 + 100 張山海立體實景長卷），在全新 Windows 11 電腦上**無須安裝 Python 或 Docker，解壓縮後雙擊 `1945-II-WarSpace.exe` 即可直接遊玩**，並支援 `F11` 隨時切換全螢幕。
- **Ubuntu 26.04 (Resolute) 與 Ubuntu 24.04 (Noble)** 原生支援。
- **具備 NVIDIA GPU 環境**：利用 NVIDIA Container Toolkit 實現 OpenGL / SDL2 硬體加速渲染，最高畫面流暢度 60 FPS。
- **無 GPU 環境**：自動平滑切換至 Mesa CPU 軟體渲染（llvmpipe），無任何缺少驅動報錯。

## 快速啟動

### 1. 執行自動化測試與驗證 (驗證 4戰機/5生命力/十分之一扣血/20關卡)
```bash
cd ~/文件/GA/game1
./run.sh --test
```

### 2. 一鍵啟動遊戲 (自動偵測 GPU 或 CPU)
```bash
./run.sh
```

### 3. 指定參數快速遊戲
```bash
./run.sh --gpu              # 強制 GPU 模式
./run.sh --cpu              # 強制 CPU 模式
./run.sh --stage 5          # 直接挑戰第 5 關
./run.sh --plane 1          # 預選第 2 款戰機 (F4U 海盜)
```

### 4. 直接由 Docker 映像檔執行 (無需原始程式碼目錄)
```bash
# 賦予 X11 顯示存取權限
xhost +local:root

# 直接使用獨立啟動腳本執行映像檔
./run-image.sh

# 或使用純 docker run 原生指令直接執行映像檔 (GPU 加速)
docker run --rm -it \
  --gpus all \
  -e DISPLAY=$DISPLAY \
  -v /tmp/.X11-unix:/tmp/.X11-unix:rw \
  -v /dev/dri:/dev/dri \
  -v /dev/snd:/dev/snd \
  -v /dev/shm:/dev/shm \
  --ipc=host \
  --network=host \
  ii-warspace-1945:latest

# 純 CPU 軟體渲染模式直接執行映像檔
docker run --rm -it \
  -e DISPLAY=$DISPLAY \
  -e LIBGL_ALWAYS_SOFTWARE=1 \
  -v /tmp/.X11-unix:/tmp/.X11-unix:rw \
  -v /dev/dri:/dev/dri \
  -v /dev/snd:/dev/snd \
  -v /dev/shm:/dev/shm \
  --ipc=host \
  --network=host \
  ii-warspace-1945:latest
```

## 映像檔匯出與跨機器部署 (Portable Docker Image)

本專案已將所有代碼、音效與 100 張 1024x10240 Google Gemini Banana 實景長卷完整打包封存為獨立映像檔：

- **映像檔標籤**：`ii-warspace-1945:latest`
- **獨立封存檔**：`II-WarSpace-1945-latest.tar.gz`

若要在其他全新機器上直接執行，只需拷貝該 `.tar.gz` 檔案並執行：
```bash
# 載入映像檔
docker load -i II-WarSpace-1945-latest.tar.gz

# 載入後直接啟動遊戲
./run-image.sh
```
